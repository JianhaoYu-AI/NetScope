# 数据与隐私

NetScope 基础观测由设备系统 API 与实际网络探针取得，失败与缺失保留原状。设备内保存的网络地址、DNS 配置、信号及 HTTP 快照属于诊断数据，应按个人或组织的数据管理要求处理。

## 本机数据

证据快照保存到应用的 Room 数据库。导出由用户选择文件位置；分享导出的 JSON 前，应检查其中的网络标识、地址与快照。历史记录与当前网络状态分开标注。

## 可选模型传输

点击模型诊断后，会把本次证据的临时副本发送到配置的网关，再由网关发送到上游模型。HTTP 快照里的 Cookie、Authorization 等敏感头在传输副本中遮蔽；本机原始观测不改写。该投影不是对全部个人信息的通用匿名化，网络地址等字段仍可能出现在请求中。

## 凭据

API Key 只由服务端进程读取环境变量。手机填写独立服务访问码，地址与访问码仅存于应用进程内，重启后需要重新设置；不写入 BuildConfig、Room 或导出档案。公开仓库只含空值环境示例，不含任何可用凭据。

## 网关日志

网关保留带 traceId 的请求、响应、状态与耗时。已知 API Key 和服务访问码会遮蔽，但证据内容仍可能进入日志。把 quota 和日志放在私密持久目录，不放入静态下载目录或版本库。保护模式额度计数要求单进程、单副本部署。
