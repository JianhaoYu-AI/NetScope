# 模型接口与工具协议

手机访问 NetScope 网关，网关使用服务端凭据访问 OpenAI 兼容上游。客户端使用完整网关路径 `/v1/chat/completions`，上游使用服务商提供的完整 `/chat/completions` URL。

## 工具集合

| 名称 | 能力 |
|---|---|
| net_overview | 本机活动网络、网络能力、路由与系统 DNS 配置 |
| wifi_detail | WiFi 连接、信号、协商速率与可取得的链路字段 |
| dns_resolve | 固定三个域名的实际解析与耗时 |
| tcp_probe | 固定两个 IP:Port 目标的实际 TCP connect |
| http_probe | 固定 HTTP(S) 目标的真实连接、握手及响应 |

工具参数必须为空 JSON 对象 `{}`。未知工具名或非空参数会被拒绝，模型不能传入新的 URL、IP、命令或系统设置。工具预算最多 8 次尝试、90 秒；拒绝的调用尝试也占预算。

## 最终输出

模型最终返回 JSON：

```json
{
  "claims": [
    {"text": "根据本次可用证据描述观测", "evidenceIds": ["E001"], "confidence": 0.5}
  ]
}
```

上述编号和内容仅说明输出格式，不是网络采集数据。实际引用必须唯一指向本次会话中可用证据；不能从失败证据的空 metrics 编造时延、成功率或具体根因。没有充分可用证据时返回空 `claims`。

配置不可用或协议失败时返回明确的模型不可用状态，保留本地采集与规则结果。最终提案审计为引用结构检查：引用合格仍可能出现自然语言语义越界，应与原始观测并列核对。

## 指标解释

- `handshakeMs` 是成功 TCP connect 耗时的中位数，不能改称平均值。
- `successCount` 是成功尝试次数，不能改称目标数。
- 系统 DNS 配置列表不能证明每次请求实际使用哪个服务器。
- 当前 `NXDOMAIN` 标签由 `UnknownHostException` 映射，不等于已验证的 DNS 报文响应码。
- WiFi 协商速率不等于互联网实测带宽。
- 标识不可得只表示这次没有读取到，不能据此断定权限故障或系统读取异常。
